# অ্যাডমিন প্যানেল — সেটআপ ও ব্যবহার গাইড

এই গাইডে আছে: নতুন অ্যাডমিন প্যানেল কোথায়, কীভাবে Neon ডেটাবেজ ও Cloudflare R2
জোড়া লাগাবেন, Cloudflare Pages-এ কী কী সেটিংস দিতে হবে, এবং প্রতিদিন কীভাবে
প্রোডাক্ট, দাম আর ল্যান্ডিং পেজ বদলাবেন।

> সংক্ষেপে: দাম ও প্রোডাক্ট এখন ডেটাবেজে থাকে, তাই **রিবিল্ড ছাড়াই** সাইটে
> পরিবর্তন দেখা যায়। ছবি যায় Cloudflare R2-তে। সার্ভিস পেজ ও ল্যান্ডিং পেজ
> Cloudflare Pages Functions দিয়ে চলে।

## ১. নতুন কী কী যোগ হয়েছে

| ফিচার | কোথায় | কী করা যায় |
| --- | --- | --- |
| প্রোডাক্ট ও দাম | `/admin/` → প্রোডাক্ট ও দাম | নতুন প্রোডাক্ট, দাম বাড়ানো/কমানো (±১০ টাকা বাটন), বাল্কে % বা ৳ পরিবর্তন, ছবি আপলোড |
| ক্যাটাগরি | `/admin/` → ক্যাটাগরি | ক্যাটাগরি যোগ/এডিট/ডিলিট, ক্রম ঠিক করা |
| নতুন ক্যাটাগরি | সিড করা আছে | **রেডিমেড ছাপালেভেল** — রেডিমেড প্রোডাক্টের নিচে আলাদা সেকশন হিসেবে দেখাবে |
| সার্ভিস | `/admin/` → সার্ভিস | সার্ভিসের দাম, সংক্ষিপ্ত বিবরণ, অর্ডারের তথ্য (Minimum Order ইত্যাদি), নোট |
| ল্যান্ডিং পেজ | `/admin/` → ল্যান্ডিং পেজ | ব্লক দিয়ে পেজ সাজানো, নির্দিষ্ট প্রোডাক্ট বসানো, **HTML কোড** দিয়ে নিজের ডিজাইন, লাইভ প্রিভিউ |
| সেটিংস | `/admin/` → সেটিংস | WhatsApp নম্বর, অফিস ফোন, বাজেট ক্যালকুলেটরের রেট, পাসওয়ার্ড, রিবিল্ড |
| রিবিল্ড | সেটিংস | Deploy hook দিয়ে sitemap/স্ট্যাটিক পেজ আপডেট |

পাবলিক সাইট প্রথম রেন্ডারে কোডে থাকা ডিফল্ট ক্যাটালগ দেখায় (SEO ও নো-JS
জন্য), তারপর `/api/catalog` থেকে লাইভ দাম বসিয়ে দেয়। API না পেলে পুরোনো
দামই দেখায় — সাইট কখনো ফাঁকা হবে না।

## ২. ধাপে ধাপে সেটআপ

### ধাপ ১ — Neon ডেটাবেজ

1. [neon.tech](https://neon.tech) এ লগইন করে **New Project** করুন
   (Region: Singapore বা যেটা ঢাকার কাছে হয়)।
2. Dashboard → **Connect** → **Connection string** কপি করুন।
   পুল করা সংযোগের জন্য হোস্টে `-pooler` থাকে, যেমন:
   `postgresql://user:pass@ep-xxx-pooler.ap-southeast-1.aws.neon.tech/neondb?sslmode=require`
3. প্রজেক্টের রুটে `.env` ফাইল বানান (`.env` কখনো Git-এ কমিট করবেন না):

   ```sh
   cp .env.example .env
   # .env খুলে DATABASE_URL, ADMIN_EMAIL, ADMIN_PASSWORD বসান
   ```

4. টেবিল তৈরি + ডিফল্ট প্রোডাক্ট সিড + অ্যাডমিন ইউজার বানান:

   ```sh
   npm ci
   npm run db:setup
   ```

   আউটপুটে `✓ Neon সেটআপ সম্পন্ন — ৩টি ক্যাটাগরি, ৫টি প্রোডাক্ট` দেখলে কাজ
   শেষ। স্ক্রিপ্টটি **বারবার চালানো নিরাপদ** — আগের দাম বা এডিট মুছে যায় না।

   শুধু পাসওয়ার্ড বদলাতে চাইলে:

   ```sh
   ADMIN_PASSWORD='নতুনপাসওয়ার্ড123' npm run db:setup
   ```

### ধাপ ২ — Cloudflare R2 (ছবির জন্য)

1. Cloudflare Dashboard → **R2** → **Create bucket** → নাম দিন, যেমন
   `smart-printing-media`।
2. বাকেটে ঢুকে **Settings → Public access**:
   - দ্রুত শুরু করতে **R2.dev public URL** চালু করুন, অথবা
   - নিজের ডোমেইন (যেমন `media.smartpackagingbd.com`) **Custom domain** হিসেবে
     যোগ করুন (এটাই প্রস্তাবিত, দ্রুত ও ব্র্যান্ডেড)।
3. যে URL পেলেন সেটি লিখে রাখুন — এটাই `R2_PUBLIC_BASE_URL`
   (শেষে `/` দেবেন না), যেমন `https://media.smartpackagingbd.com`।

> R2-তে আলাদা API টোকেন লাগবে না — Cloudflare Pages Function সরাসরি বাকেটে
> লিখবে (binding দিয়ে)। ছবি আপলোড হবে `/api/admin/upload` দিয়ে।

### ধাপ ৩ — Cloudflare Pages সেটিংস

Cloudflare Dashboard → **Workers & Pages** → আপনার Pages প্রজেক্ট →
**Settings**:

1. **Build**:
   - Build command: `npm run build`
   - Build output directory: `dist`
2. **Variables and Secrets** (Production ও Preview দুটোতেই দিন):

   | নাম | মান | আবশ্যক |
   | --- | --- | --- |
   | `DATABASE_URL` | Neon-এর `-pooler` কানেকশন স্ট্রিং | হ্যাঁ |
   | `R2_PUBLIC_BASE_URL` | `https://media.smartpackagingbd.com` | হ্যাঁ |
   | `SITE_URL` | `https://smartpackagingbd.com` | ঐচ্ছিক |
   | `DEPLOY_HOOK_URL` | Deploy hook-এর URL | ঐচ্ছিক |
   | `R2_UPLOAD_MAX_MB` | `8` (ডিফল্ট) | ঐচ্ছিক |
   | `CATALOG_API_URL` | `https://smartpackagingbd.com` | ঐচ্ছিক |

   `CATALOG_API_URL` দিলে প্রতিটি বিল্ডে ল্যান্ডিং পেজগুলো sitemap-এ যোগ হবে।
3. **Functions → R2 bucket bindings**: Variable name **`MEDIA`**, বাকেট
   `smart-printing-media` — Save করুন।
4. ভেরিয়েবল যোগ করার পর **একবার Redeploy** করতে হবে (আগের ডিপ্লয়ে env থাকে না)।

> `functions/` ফোল্ডার রিপোজিটরির রুটে থাকলেই Pages নিজে থেকে Functions
> চালু করে। `public/_routes.json` শুধু `/api/*` আর `/lp/*` রুটে Function
> ডাকবে, তাই সাইটের বাকি পেজ আগের মতোই স্ট্যাটিক।

### ধাপ ৪ — প্রথম লগইন

1. `https://smartpackagingbd.com/admin/` এ যান।
2. `.env`-এ দেওয়া `ADMIN_EMAIL` / `ADMIN_PASSWORD` দিয়ে লগইন করুন।
3. **সেটিংস → পাসওয়ার্ড বদলান** দিয়ে শক্তিশালী পাসওয়ার্ড দিন
   (কমপক্ষে ১০ অক্ষর, অন্তত একটি সংখ্যা)। পাসওয়ার্ড বদলালে সব পুরোনো সেশন
   বাতিল হয়ে যায়।

### ধাপ ৫ (প্রস্তাবিত) — Cloudflare Access

Cloudflare Zero Trust → **Access → Applications → Add** → Self-hosted →
ডোমেইন `smartpackagingbd.com`, path `admin*` → শুধু আপনার ইমেইল দিয়ে
One-time PIN policy দিন। এতে প্যানেলের সামনে আরেক স্তর সুরক্ষা থাকে।

## ৩. প্রতিদিনের ব্যবহার

### দাম কমানো / বাড়ানো

- **দ্রুত পদ্ধতি:** প্রোডাক্ট লিস্টে প্রতিটি প্রোডাক্টের পাশে লাল (‑১০) ও
  সবুজ (+১০) বাটন। চাপলেই সাথে সাথে সেভ হয়ে যায়।
- **নির্দিষ্ট দাম:** “সম্পাদনা” → দাম / সর্বোচ্চ দাম / একক → সেভ।
- **একসাথে সব:** “একসাথে দাম বদলান” → কোথায় (সব প্রোডাক্ট বা একটি
  ক্যাটাগরি) → ধরন (৳ বা %) → যেমন `-10` বা `5` → প্রয়োগ।
- প্রতিটি দাম পরিবর্তনের হিসাব `price_history` টেবিলে জমা থাকে (অডিট)।

দাম সাইটে দেখা যাবে ৩০–৬০ সেকেন্ডের মধ্যে (CDN ক্যাশ), হার্ড রিফ্রেশ করলে
সাথে সাথে।

### নতুন প্রোডাক্ট ও ছবি

1. **প্রোডাক্ট ও দাম → নতুন প্রোডাক্ট**।
2. নাম (বাংলা) দিন; ইংরেজি নাম দিলে URL slug নিজে তৈরি হবে।
3. **ছবি → R2-তে আপলোড করুন** (JPG/PNG/WebP, সর্বোচ্চ ৮ MB)। চাইলে সরাসরি
   URL-ও বসাতে পারেন।
4. ক্যাটাগরি, দাম, একক, ন্যূনতম অর্ডার, WhatsApp মেসেজ দিয়ে **সেভ**।

### “রেডিমেড ছাপালেভেল” ক্যাটাগরি

এটি আগেই তৈরি আছে এবং রেডিমেড প্রোডাক্টের **নিচে আলাদা সেকশন** হিসেবে
দেখাবে। এখন এতে কোনো প্রোডাক্ট নেই, তাই সাইটে সেকশনটি লুকানো থাকে — এই
ক্যাটাগরিতে প্রথম প্রোডাক্ট যোগ করলেই সেকশনটি নিজে থেকে দেখা যাবে।
নাম বদলাতে চাইলে **ক্যাটাগরি → সম্পাদনা**।

### সার্ভিস পেজ

**সার্ভিস** ট্যাবে ১০টি সার্ভিসের দাম, সংক্ষিপ্ত বিবরণ, অর্ডারের তথ্য (Minimum
Order, Thickness ইত্যাদি) ও নোট বদলানো যায়। বড় লেখা (কী, সুবিধা, তুলনা)
কোডে থাকে — সেগুলো বদলাতে ডেভেলপার লাগবে।

### ল্যান্ডিং পেজ

1. **ল্যান্ডিং পেজ → নতুন ল্যান্ডিং পেজ**।
2. নাম ও slug দিন (যেমন `ready-made-offer`) → লিংক হবে `/lp/ready-made-offer/`।
3. “নতুন ব্লক যোগ করুন” থেকে ব্লক বসান:
   - **হিরো** — বড় শিরোনাম, ছবি, বাটন
   - **প্রোডাক্ট গ্রিড** — চেকবক্স দিয়ে নির্দিষ্ট প্রোডাক্ট বাছাই (দাম ও
     WhatsApp অর্ডার বাটন নিজে থেকে বসবে)
   - **ফিচার / সুবিধা**, **ছবি**, **CTA ব্যানার**, **প্রশ্ন-উত্তর**
   - **লেখা** — HTML দিয়ে রিচ টেক্সট
   - **HTML কোড** — পুরো ডিজাইন নিজের HTML/CSS দিয়ে করতে চাইলে এই ব্লক।
     `script` চালু করতে চাইলে আলাদা সুইচ আছে (শুধু বিশ্বস্ত কোডে ব্যবহার করুন)।
4. “প্রিভিউ” ট্যাবে দেখে নিন → **সেভ করুন** → “প্রকাশিত” চালু করুন।
5. লাইভ লিংক: `https://smartpackagingbd.com/lp/<slug>/`

ল্যান্ডিং পেজ Cloudflare Pages Function দিয়ে সার্ভার-রেন্ডার হয়, তাই
Google-ও পূর্ণ HTML দেখে (SEO টাইটেল, বর্ণনা, canonical, JSON-LD সহ)।

sitemap-এ নতুন পেজ যোগ করতে **সেটিংস → রিবিল্ড শুরু করুন**
(`DEPLOY_HOOK_URL` সেট থাকলে)।

## ৪. লোকাল ডেভেলপমেন্ট

```sh
npm ci
npm run dev          # সাইট: http://localhost:5173  ·  অ্যাডমিন: /admin/
```

শুধু UI দেখতে এই ভাবে চলবে (ডেটা কোডের ডিফল্ট ক্যাটালগ থেকে আসবে, অ্যাডমিন
লগইন কাজ করবে না)। পুরো স্ট্যাক (API + ডেটাবেজ + R2) লোকালে চালাতে:

```sh
npm run build
npx wrangler pages dev dist \
  --binding DATABASE_URL="<neon connection string>" \
  --binding R2_PUBLIC_BASE_URL="https://media.example.com" \
  --r2 MEDIA
```

`wrangler` প্রথমবার জিজ্ঞেস করলে ইনস্টল হতে দেবে। লোকাল R2 সিমুলেশনে আপলোড
হলেও পাবলিক URL কাজ করবে না — তাই আসল ছবি দেখতে আসল R2 ব্যবহার করুন।

যাচাই করার কমান্ড:

```sh
npm run typecheck
npm run build
npm run test:seo
```

## ৫. নিরাপত্তা

- `.env`, `.dev.vars` — Git-এ যায় না (`.gitignore`-এ আছে)। ডেটাবেজ URL বা
  পাসওয়ার্ড কখনো কোডে/চ্যাটে লিখবেন না।
- পাসওয়ার্ড PBKDF2-SHA256 (২,১০,০০০ রাউন্ড) দিয়ে হ্যাশ হয়ে জমা থাকে।
- সেশন কুকি `HttpOnly; Secure; SameSite=Strict`, মেয়াদ ৭ দিন; পাসওয়ার্ড
  বদলালে সব সেশন বাতিল।
- লেখা (POST/PUT/DELETE) রিকোয়েস্টে Origin যাচাই হয়; ভুল আইডি/স্লাগ
  প্রত্যাখ্যাত হয়।
- `/admin/` পেজে `noindex` মেটা ও `X-Robots-Tag: noindex` হেডার আছে
  (`public/_headers`)। তবুও Cloudflare Access দিয়ে ঢেকে রাখাই ভালো।
- সন্দেহ হলে Neon Dashboard → Roles → পাসওয়ার্ড রিসেট করুন, নতুন
  `DATABASE_URL` বসিয়ে Pages-এ redeploy করুন।

## ৬. সমস্যা ও সমাধান

| যা দেখছেন | কারণ | সমাধান |
| --- | --- | --- |
| “ডেটাবেজ কনফিগার করা হয়নি (DATABASE_URL)” | Pages-এ env var নেই বা redeploy হয়নি | Variables-এ `DATABASE_URL` দিন → Redeploy |
| “R2 বাকেট বাঁধা নেই” | R2 binding নেই | Settings → Functions → R2 bucket bindings → `MEDIA` |
| “R2_PUBLIC_BASE_URL সেট করা নেই” | পাবলিক URL env নেই | R2 Custom domain / r2.dev URL বসান |
| লগইনে “ইমেইল বা পাসওয়ার্ড সঠিক নয়” | অ্যাডমিন ইউজার নেই / পাসওয়ার্ড ভুল | `ADMIN_PASSWORD='...' npm run db:setup` |
| সাইটে পুরোনো দাম | CDN ক্যাশ (৩০–৬০ সে.) | হার্ড রিফ্রেশ / ১ মিনিট অপেক্ষা |
| `/lp/...` এ ৪০৪ | পেজ “প্রকাশিত” নয় বা slug ভুল | ল্যান্ডিং পেজে প্রকাশিত চালু করুন |
| ছবি আপলোডে ৪১৩ | ফাইল ৮ MB-এর বেশি | ছবি ছোট করুন বা `R2_UPLOAD_MAX_MB` বাড়ান |
| অ্যাডমিন সাদা পেজ | JS ফাইল পুরোনো ক্যাশ | Ctrl+Shift+R |
| রিবিল্ড বাটনে এরর | `DEPLOY_HOOK_URL` নেই | Pages → Builds → Deploy hooks → নতুন hook |

ডেটাবেজে সমস্যা হলে Neon Dashboard → **SQL Editor**-এ চালিয়ে দেখতে পারেন:

```sql
select count(*) from products;
select key, value from site_settings;
select * from price_history order by changed_at desc limit 20;
```

## ৭. কোন ফাইল কী কাজ করে

| ফাইল / ফোল্ডার | কাজ |
| --- | --- |
| `db/schema.sql` | টেবিলের কাঠামো |
| `data/seed/catalog.json` | ডিফল্ট ক্যাটাগরি, প্রোডাক্ট ও সেটিংস |
| `scripts/db-setup.mjs` | টেবিল তৈরি + সিড + অ্যাডমিন ইউজার |
| `functions/api/catalog.ts` | পাবলিক প্রোডাক্ট/দাম API |
| `functions/api/admin/*` | লগইন, প্রোডাক্ট, ক্যাটাগরি, সার্ভিস, ল্যান্ডিং পেজ, আপলোড |
| `functions/lp/[slug].ts` | ল্যান্ডিং পেজ সার্ভার-রেন্ডার |
| `src/admin/*` | অ্যাডমিন প্যানেলের UI |
| `src/lib/catalog.ts` | সাইটে লাইভ দাম বসানোর লজিক |
| `public/_headers`, `public/_routes.json` | Pages হেডার ও Function রুট |

## ৮. আগামীতে যা যোগ করা যায়

- ছবির `gallery` (একাধিক ছবি) অ্যাডমিন UI-তে দেখানো — ডেটাবেজে ফিল্ড আছে,
  UI-তে এক ছবি দেখানো হয়
- অর্ডার ফর্ম ডেটাবেজে জমা রাখা ও অ্যাডমিনে লিস্ট
- প্রোডাক্ট সার্চ/ফিল্টার পেজের URL (`/products/`) — এখন হোমপেজেই ফিল্টার
- ডিসকাউন্ট ব্যাজ/কুপন, একাধিক অ্যাডমিন ইউজার ও রোল
- ছবি আপলোডে অটো WebP কম্প্রেশন
